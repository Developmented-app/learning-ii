Google Sheets Database Sync

Connect your system to Google Sheets. All notes, marks, and quiz progress will save to your own Cloud Spreadsheet.

Setup steps for API deployment:

  1. Create a Google Sheet and open Extensions > Apps Script.
  2. Paste the code from google_apps_script.js.
  3. Click Deploy > New Deployment and select Web App.
  4. Set Execute as: Me and Who has access: Anyone.
  5. Copy and paste your generated Web App URL in the field above.
